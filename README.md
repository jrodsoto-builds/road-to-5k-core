# road-to-5k-core — pre-event build (dependency)

The Road to 5K app as it stood before the Meta Global AI Developer
Hackathon building period: Sessions 1–6 (Oct 15–25, 2026), ending at the
Oct 23, 2026 state (source commit f4704a5).

This repository is PRIOR WORK. It is published as the pinned dependency
of the hackathon submission repo
(https://github.com/jrodsoto-builds/road-to-5k), which pins this repo as
a git submodule at that state and overlays the files built or changed
during the event (Oct 27 – Nov 4, 2026). Diffing any file in the
submission repo against the same path here shows exactly what the event
changed.
